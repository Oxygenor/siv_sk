# Сайт КЗ «Сиваковецька гімназія»

Сучасний сайт школи на React (Vite). Повністю статичний — увесь текстовий контент
живе прямо в коді, без бази даних і без адмін-панелі. Розміщується безкоштовно на
GitHub Pages.

## Структура проєкту

```
src/
  components/   — навігація, футер, картки новин, галерея тощо
  pages/        — сторінки сайту
  data/         — увесь контент сайту (новини, документи, галерея, розділи, контакти, персонал, посилання)
  styles/       — спільні стилі окремих блоків
  utils/        — допоміжні функції (посилання на файли в public/)
public/
  documents/, gallery/, news/, sections/ — сюди завантажуються реальні файли (див. розділ 2)
.github/workflows/deploy.yml — автоматичний деплой на GitHub Pages
```

## 1. Локальний запуск

```
npm install
npm run dev
```

## 2. Як додати чи змінити контент

Весь контент сайту редагується прямо у файлах `src/data/*.js` через веб-інтерфейс
GitHub (олівець «Edit this file» на сторінці файлу в репозиторії) — програмувати
не потрібно, достатньо скопіювати приклад і вставити свої дані. Після збереження
(«Commit changes») сайт автоматично перезбереться за ~1 хвилину (вкладка **Actions**).

- **Новини** — `src/data/news.js`. Додайте новий об'єкт на початок масиву `news`
  (найновіші зверху), приклад є в коментарі на початку файлу.
- **Документи** (розклад, статут, звітність тощо) — `src/data/documents.js`.
  Спершу завантажте сам файл у `public/documents/` (кнопка **Add file → Upload
  files** у цій папці на GitHub), потім додайте до відповідного пункту в
  `documents.js` поле `filename` з точною назвою файлу (великі/малі літери мають
  збігатись). Поки `filename` не вказано — на сайті буде позначка «буде додано
  найближчим часом».
- **Фотогалерея** — спершу завантажте фото в `public/gallery/`, потім додайте
  запис у масив `gallery` в `src/data/gallery.js` (приклад у коментарі).
- **Додаткові розділи** (доступні за адресою `/rozdily/назва`) — масив `sections`
  у `src/data/sections.js`; за бажанням можна прикріпити файл із `public/sections/`.
- **Контакти, персонал, посилання** — `src/data/school.js`, `staff.js`, `links.js`.

Видалення запису з масиву прибирає його з сайту, але не видаляє сам файл із
GitHub — за потреби видаліть файл окремо в тій самій папці репозиторію.

Контактна форма (`/kontakty`) нікуди нічого не зберігає — кнопка «Надіслати»
просто відкриває поштову програму відвідувача з готовим листом на пошту школи.

## 3. Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub і залийте туди цей проєкт.
2. У репозиторії: **Settings → Pages → Source → GitHub Actions**.
3. Зробіть `git push` у гілку `main` — сайт автоматично збереться й опублікується
   (прогрес можна побачити у вкладці **Actions**). Готовий сайт буде доступний за адресою
   `https://<ваш-акаунт>.github.io/<назва-репозиторію>/`.

Кожен наступний `git push` у `main` автоматично оновлює сайт.

## 4. Що перенесено зі старого сайту

Весь текстовий контент, контакти, перелік персоналу, корисні посилання та перелік подій
2025–2026 н.р. перенесено безпосередньо в код (`src/data/`). Розклад уроків, правила
поведінки, критерії оцінювання, статут та інші офіційні документи на старому сайті були
вбудованими Word/PDF-файлами — на новому сайті для них підготовлені місця (розділи
«Учням», «Батькам», «Документи»), куди потрібно один раз завантажити самі файли (див. розділ 2).
