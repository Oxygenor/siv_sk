# Сайт КЗ «Сиваковецька гімназія»

Сучасний сайт школи на React (Vite) з адмін-панеллю на базі Firebase. Розміщується
безкоштовно на GitHub Pages.

## Структура проєкту

```
src/
  components/   — навігація, футер, картки новин, галерея тощо
  pages/        — публічні сторінки сайту
  admin/        — захищена адмін-панель (новини, документи, галерея, розділи, повідомлення)
  data/         — статичний контент, перенесений зі старого сайту (контакти, персонал, посилання)
  firebase/      — підключення до Firebase (auth, firestore, storage)
  hooks/         — React-хуки для роботи з даними у реальному часі
  styles/        — спільні стилі окремих блоків
firestore.rules  — правила безпеки бази даних
storage.rules    — правила безпеки сховища файлів
.github/workflows/deploy.yml — автоматичний деплой на GitHub Pages
```

## 1. Налаштування Firebase (безкоштовно, ~10 хвилин)

1. Перейдіть на [console.firebase.google.com](https://console.firebase.google.com/) та створіть новий проєкт (карта не потрібна — тариф Spark безкоштовний).
2. **Authentication** → Sign-in method → увімкніть «Email/Password». Потім у вкладці Users додайте одного користувача (email + пароль) — це і буде логін адміністратора сайту.
3. **Firestore Database** → Create database → почніть у тестовому режимі (пізніше застосуємо власні правила з `firestore.rules`).
4. **Storage** → Get started (для зберігання фото та документів).
5. У налаштуваннях проєкту (⚙️ → Project settings → Your apps) створіть Web-застосунок і скопіюйте конфігурацію `firebaseConfig`.
6. Встановіть Firebase CLI (`npm install -g firebase-tools`), увійдіть (`firebase login`) і опублікуйте правила безпеки:
   ```
   firebase deploy --only firestore:rules,storage:rules --project ВАШ_PROJECT_ID
   ```

## 2. Локальний запуск

```
cp .env.example .env.local
# вставте значення firebaseConfig у .env.local
npm install
npm run dev
```

## 3. Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub і залийте туди цей проєкт.
2. У репозиторії: **Settings → Pages → Source → GitHub Actions**.
3. У **Settings → Secrets and variables → Actions** додайте секрети з такими ж назвами й значеннями, що й у вашому `.env.local`:
   `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`,
   `VITE_FIREBASE_STORAGE_BUCKET`, `VITE_FIREBASE_MESSAGING_SENDER_ID`, `VITE_FIREBASE_APP_ID`.
4. Зробіть `git push` у гілку `main` — сайт автоматично збереться й опублікується
   (прогрес можна побачити у вкладці **Actions**). Готовий сайт буде доступний за адресою
   `https://<ваш-акаунт>.github.io/<назва-репозиторію>/`.

Кожен наступний `git push` у `main` автоматично оновлює сайт.

## 4. Робота з адмін-панеллю

Відкрийте `/admin` на сайті, увійдіть під email/паролем, який ви створили в кроці 1.2.
В адмінці можна:
- публікувати новини та оголошення;
- завантажувати офіційні документи (розклад, статут, звітність тощо) — вони одразу
  з’являться на відповідних сторінках замість позначки «буде додано найближчим часом»;
- завантажувати фото в галерею (з групуванням по альбомах);
- створювати нові довільні розділи сайту (доступні за адресою `/rozdily/назва`);
- переглядати повідомлення з контактної форми.

## 5. Що перенесено зі старого сайту

Весь текстовий контент, контакти, перелік персоналу, корисні посилання та перелік подій
2025–2026 н.р. перенесено безпосередньо в код (`src/data/`). Розклад уроків, правила
поведінки, критерії оцінювання, статут та інші офіційні документи на старому сайті були
вбудованими Word/PDF-файлами — на новому сайті для них підготовлені місця (розділи
«Учням», «Батькам», «Документи»), куди потрібно один раз завантажити самі файли через
адмін-панель.
